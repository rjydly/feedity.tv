===============================================================================
FEEDITY VIDEO PIPELINE — ESPECIFICACIÓ TÈCNICA I ARQUITECTURA DEL SISTEMA
===============================================================================
Fitxer de referència tècnica per a desenvolupadors i models d'IA.
Data de revisió: Octubre 2026
Objectiu: Normalització, comprensió visual, redisseny tipogràfic dual,
generació de portades editorials, traçabilitat per ID i publicació
multicanal 100% autònoma de vídeos curts en format vertical 9:16 (1080x1920 px)
a Facebook Reels, Instagram Reels, TikTok, YouTube Shorts i Snapchat Spotlight.

-------------------------------------------------------------------------------
1. VISIÓ GENERAL DE L'ARQUITECTURA DUAL I FLUX DE DADES
-------------------------------------------------------------------------------

El sistema combina una capa serverless d'ingesta ràpida (Telegram + Cloudflare)
i un scraper matinal intel·ligent (Apify) amb un motor d'edició a GitHub Actions
(orquestrat externament des de cron-job.org) i un despatxador multicanal:

1. Ingesta i Cua de Contingut:
   - Ingesta Immediata: Compartició manual via bot de Telegram -> Cloudflare Worker -> sources.csv.
   - Scraper Matinal (morning_scraper.py): Execució diària via Apify sobre comptes
     de referència (accounts.csv). Selecciona els 3 millors Reels per likes a
     today_queue.json i nodreix backup_reels.csv ordenat per viralitat.
2. Orquestració i Fallback (publisher_runner.py):
   Executa el pipeline fins a 5 intents. Si un Reel falla o està esborrat, el
   marca com a 'failed' i salta immediatament al següent de today_queue o backup.
3. Descàrrega de Vídeo (yt-dlp):
   Descàrrega en format MP4 (suport de cookies.txt i gestió d'àudio).
4. Visió per Computador (OpenCV + NumPy):
   Detecció del requadre del vídeo real mitjançant anàlisi de moviment temporal
   (Motion Seed) i refinament estàtic de vores (refine_box_to_edges).
5. Intel·ligència Artificial Multimodal (Gemini 3.x Flash -> Groq Fallback):
   Comprensió de l'escena, identificació de l'autor primari, titular editorial,
   generació de caption complet i creació DUAL de textos:
   - facebook_text: Narrativa explicativa llarga per a Facebook.
   - short_hook: Ganxo directe d'1-2 línies en gran per a formats curts.
6. Motor Tipogràfic i Sistema de Color (Pillow):
   - Tipografia oficial Plus Jakarta Sans (Regular, SemiBold, Bold).
   - Paraules en negreta (**bold**) ressaltades en groc corporatiu #e3b100 (227, 177, 0).
   - Tokenitzador intel·ligent anti-puntuació orfe (enganxa signes .,!?:; al mot anterior).
7. Disseny de Portada Editorial (Pillow):
   Llenç 1080x1920 negre sòlid, fons desenfocat (Gaussian Blur), titular 76pt
   i logotip corporatiu de 190px centrats a la Safe Zone 1:1 (y = 960 px),
   desat a videos/final_thumbnail.jpg.
8. Composició DUAL de Vídeo i Frame 0 (MoviePy 2.x):
   A partir del mateix crop base, es generen dos fitxers .mp4 independents amb
   incrustació de la miniatura com a primer fotograma (Frame 0: 33.3 ms):
   - Vídeo A (Facebook - video_{id}_fb.mp4): Capçalera Tweet completa + retall
     estricte a 85 segons (01:25) per evitar el rebuig del límit de Facebook Reels.
   - Vídeo B (Shorts - video_{id}_shorts.mp4): Capçalera compacta amb logo a
     sobre i text curt en gran (sense punt final) a sota, mantenint durada original.
9. Sincronització Git Segura (push_media_to_github):
   Verificació d'existència de fitxers (evitant errors fatals de pathspec), neteja
   de videos/, git add -> commit -> pull --rebase -> push abans de cridar les APIs.
10. Despatxador Multicanal:
    - Buffer GraphQL: Envia Vídeo A a Facebook Reels i Vídeo B a Instagram i TikTok.
    - Zernio REST API: Publica Vídeo B a YouTube Shorts (amb títol curt + #shorts).
    - Bundle.social API: Publica Vídeo B a Snapchat Spotlight (filtre VIP: quota
      mensual de 20 posts, mínim 10.000 likes i màxim 1 al dia).
11. Traçabilitat per ID i Històric:
    Incrustació de 'ID: #{tracking_id}' a tots els captions i registre complet
    a published_posts.csv (likes inicials, @compte original, data, estat de xarxes).
12. Despatxador de Notificacions (Telegram):
    - TEST_MODE = True: Envia tots dos vídeos (Facebook i Shorts), portada i caption.
    - TEST_MODE = False: Envia missatge breu de confirmació de despatx multicanal.


-------------------------------------------------------------------------------
2. INGESTA, CUA I GESTIÓ D'ESTATS
-------------------------------------------------------------------------------

A. Fitxers de Cua i Estat:
   - sources.csv: Format 'reel_url,status' ('pending', 'done', 'failed').
   - today_queue.json: Top 3 Reels seleccionats cada matí per Apify.
   - backup_reels.csv: Pool general de contingut ordenat de més a menys likes.
   - processed_videos.json: Historial d'IDs únics per garantir idempotència dual.

B. Gestor d'Execució (publisher_runner.py):
   - Extreu el següent candidat vàlid de today_queue.json o backup_reels.csv.
   - Executa precheck_reel amb yt-dlp (skip_download=True) per descartar ràpidament
     posts sense vídeo o esborrats sense gastar intents.
   - Actualitza sources.csv i llança main.py amb suport de fins a 5 reintents.


-------------------------------------------------------------------------------
3. VISIÓ PER COMPUTADOR I CROP INTEL·LIGENT (ROI)
-------------------------------------------------------------------------------

A. Algorisme Temporal Basat en Moviment (find_motion_seed):
   - Mostreja 12 parells de fotogrames (gap de 0.5s) al llarg del clip.
   - Calcula la diferència absoluta de píxels amb llindar de soroll adaptatiu.
   - Les zones que canvien amb el temps (contingut dinàmic) defineixen la 'llavor'
     de moviment, ignorant elements estàtics (marcs, text, capçaleres de mems).
   - Aplica operacions morfològiques (CLOSE de 25px i OPEN de 5px) i components
     connectats per aïllar el bloc principal.

B. Refinament Estàtic de Vores (refine_box_to_edges):
   - Genera la imatge de mediana temporal en gris (fons estàtic).
   - Camina cap a l'exterior des de la llavor buscant salts de brillantor
     coherents (>10 unitats) seguits de franges planes (fons exterior o marc).
   - Aplica un marge de seguretat intern (CROP_INNER_MARGIN = 0.6%) per eliminar
     línies negres o vores residuals de marcs originals.


-------------------------------------------------------------------------------
4. INTEL·LIGÈNCIA ARTIFICIAL MULTIMODAL I PROMPTING DUAL
-------------------------------------------------------------------------------

A. Jerarquia de Models (Failover Queue):
   1. Google Gemini (Principal - SDK google-genai):
      'gemini-3.8-flash' -> 'gemini-3.7-flash' -> 'gemini-3.6-flash' -> 'gemini-3.5-flash'.
   2. Groq Cloud (Fallback - SDK groq):
      'qwen/qwen3.8-27b' (Multimodal) -> 'openai/gpt-oss-120b' -> 'llama-3.3-70b-versatile'.

B. Estructura de Resposta JSON:
   - 'credits': Autor original identificat (ignorant comptes agregadors/reposters).
   - 'facebook_text': Paràfrasi explicativa en anglès (1-2 paràgrafs, 2-4 paraules en **bold**).
   - 'short_hook': Ganxo d'alta intensitat d'1 o 2 línies (6-12 paraules, sense punt final,
     1-3 paraules clau en **bold**).
   - 'thumbnail_title': Titular agressiu en majúscules de 3 a 6 paraules.
   - 'generated_caption': Història explicativa + CTA + 8-12 hashtags + crèdits.


-------------------------------------------------------------------------------
5. MOTOR TIPOGRÀFIC I DISSENY DE CAPÇALERES (Pillow)
-------------------------------------------------------------------------------

A. Sistema Tipogràfic i Colors:
   - Font: Plus Jakarta Sans descarregada automàticament a assets/fonts/.
   - Color Text Regular: Blanc pur (255, 255, 255).
   - Color Negreta (**bold**): Groc corporatiu #e3b100 (227, 177, 0) a 54pt.
   - Color Metadades: Gris #71767B.

B. Tokenitzador Anti-Puntuació Òrfena (tokenize_markdown_text):
   En separar blocs amb asteriscs **, si el caràcter següent és un signe de
   puntuació aïllat (.,!?:;), s'acobla automàticament a la paraula precedent,
   evitant espais erronis davant del punt (p. ex. 'pure chills .').

C. Capçalera 1: Facebook (create_facebook_header_image):
   - Avatar circular de 110px a l'esquerra (assets/logo.png).
   - Nom 'Feedity' (48pt SemiBold) i usuari '@feedity.tv' (38pt Regular).
   - Cos del text: 44pt amb salts de línia precisos i paraules destacades en groc.

D. Capçalera 2: Shorts (create_shorts_header_image):
   - Logo centrat a la part superior (diàmetre 96px).
   - Text curt de màxim 2 línies (52pt SemiBold i 54pt Bold groc) centrat
     horitzontalment a sota del logo.
   - Eliminació estricta de punts finals per estètica short-form.


-------------------------------------------------------------------------------
6. COMPOSICIÓ DUAL DE VÍDEO I LIMITACIONS DE PLATAFORMA (MoviePy 2.x)
-------------------------------------------------------------------------------

A. Composició Base (1080x1920 px):
   - Fons negre sòlid.
   - Vídeo retallat centrat horitzontalment a 1080px d'amplada.
   - Primer fotograma: Frame 0 de la portada editorial (durada 1/30 segons = 33.3 ms).

B. Vídeo A — Facebook Reels ('videos/video_{id}_fb.mp4'):
   - Capçalera Facebook situada a y = 180 px.
   - RETALL DE SEGURETAT DE DURADA: Facebook Reels rebutja continguts de més de 90s.
     Si el vídeo original supera els 85 segons (01:25), s'aplica automàticament
     clip.subclipped(0, 85.0) tant al vídeo com a l'àudio i la capçalera.

C. Vídeo B — Shorts ('videos/video_{id}_shorts.mp4'):
   - Capçalera Shorts situada a y = 140 px.
   - Manté la durada original íntegra (suportat per IG, TikTok, YouTube Shorts i Snap).


-------------------------------------------------------------------------------
7. DISTRIBUCIÓ MULTICANAL I ENRUTAMENT
-------------------------------------------------------------------------------

A. Publicació via Buffer (GraphQL API):
   - Canal Facebook: Envia la URL pública de 'videos/video_{id}_fb.mp4'.
   - Canals Instagram i TikTok: Envia la URL pública de 'videos/video_{id}_shorts.mp4'.
   - Metadades: Injecta type: "reel" i shouldShareToFeed: true segons la xarxa.

B. Publicació a YouTube Shorts via Zernio API (REST):
   - Endpoint: POST https://zernio.com/api/v1/posts
   - Detecció automàtica: YouTube detecta Shorts per relació d'aspecte (9:16) i durada (<3 min).
   - Títol: '{short_hook} #shorts' (màxim 100 caràcters).
   - Descripció: Caption complet amb ID i disclaimer (fins a 5.000 caràcters).
   - Miniatura: YouTube no permet caràtules externes per API a Shorts; s'extreu
     del propi fitxer (on ja hi ha el Frame 0).
   - Paràmetres: visibility: "public", madeForKids: false, categoryId: "22".

C. Publicació a Snapchat Spotlight via Bundle.social:
   - Filtre VIP i Quota: Gestionat per snapchat_tracker.json (màxim 20 posts/mes).
     Només es publica si el vídeo té >= 10.000 likes i és el primer post del dia.
   - Durada admissible: 5 a 180 segons.
   - Descripció de Spotlight: Màxim estricte de 160 caràcters (inclou '#{tracking_id}').
   - Procés en 2 passos: Upload del fitxer a /v1/upload i POST a /v1/post.


-------------------------------------------------------------------------------
8. TRAÇABILITAT, IDENTIFICADORS I REGISTRE (published_posts.csv)
-------------------------------------------------------------------------------

A. Identificador Universal (tracking_id):
   S'extreu del shortcode únic d'Instagram o timestamp numèric. S'insereix al
   final de totes les descripcions de totes les xarxes socials:
   'ID: #{tracking_id}'

B. Fitxer de Registre Centralitzat (published_posts.csv):
   Desa cada publicació amb les columnes:
   - id: Identificador imprès al caption.
   - shortcode: Codi únic d'Instagram original.
   - source_url: Enllaç complet al vídeo d'origen descarregat.
   - source_account: Nom d'usuari (@compte) del qual s'ha extret el vídeo.
   - initial_likes: Nombre de likes que tenia el vídeo a l'scraping original.
   - thumbnail_title: Titular editorial generat per la IA.
   - published_date: Data i hora UTC (YYYY-MM-DD HH:MM:SS).
   - snapchat_published: 'yes' o 'no'.
   - youtube_published: 'yes' o 'no'.


-------------------------------------------------------------------------------
9. SINCRONITZACIÓ GIT A PROVA DE FALLADES (push_media_to_github)
-------------------------------------------------------------------------------

Per evitar bloquejos de rebase i errors fatals de Git a GitHub Actions:
1. Inicialització prèvia (init_tracking_files): Assegura que snapchat_tracker.json
   i published_posts.csv existeixen a disc abans de cap comanda Git.
2. Filtratge de Targets: S'escaneja la llista de fitxers i es fa 'git add'
   ÚNICAMENT dels que realment existeixen a disc (evitant 'fatal: pathspec did not match').
3. Ordre Correcte de Commit/Rebase:
   - S'executa 'git add' dels canvis locals.
   - S'executa 'git commit' (si hi ha canvis staged).
   - S'executa 'git pull --rebase origin main' (net, sense unstaged changes).
   - S'executa 'git push origin main'.
4. Retard de seguretat (4s) per garantir propagació a raw.githubusercontent.com.


-------------------------------------------------------------------------------
10. MODES D'OPERACIÓ (TEST_MODE) I TELEGRAM
-------------------------------------------------------------------------------

A. Mode de Proves (TEST_MODE = True):
   - NO publica a Buffer, Zernio ni Bundle.social.
   - NO actualitza el comptador de Snapchat ni afegeix files a published_posts.csv.
   - Envia per Telegram:
     * Vídeo 1: Versió Facebook (Text llarg explicatiu).
     * Vídeo 2: Versió Shorts (Text gran groc IG/TikTok/YouTube/Snap).
     * Foto: Portada editorial (final_thumbnail.jpg).
     * Text: Caption complet amb ID.

B. Mode de Producció (TEST_MODE = False):
   - Publica simultàniament a totes les xarxes configurades.
   - Registra l'estat a processed_videos.json, sources.csv i published_posts.csv.
   - Envia per Telegram únicament un missatge breu de text de confirmació.


-------------------------------------------------------------------------------
11. ORQUESTRACIÓ TEMPORAL I SECRETS REQUERITS
-------------------------------------------------------------------------------

A. Execució i Cron:
   L'activació periòdica (10 cops al dia en horaris punta dels EUA) s'executa
   des de cron-job.org disparant 'workflow_dispatch' a l'API de GitHub Actions,
   garantint puntualitat exacta sense els retards del cron intern de GitHub.

B. Secrets a GitHub Actions:
   - TELEGRAM_BOT_TOKEN       : Token del bot de Telegram.
   - TELEGRAM_CHAT_ID         : Chat ID del receptor d'alertes i proves.
   - GEMINI_API_KEY           : Clau d'API de Google AI Studio.
   - GROQ_API_KEY             : Clau d'API de Groq Cloud (Fallback).
   - BUFFER_ACCESS_TOKEN      : Token d'accés de Buffer.
   - BUFFER_CHANNEL_IDS       : IDs dels canals de Buffer (FB, IG, TikTok).
   - ZERNIO_API_KEY           : Clau d'API de Zernio.
   - ZERNIO_YT_ACCOUNT_ID     : ID del compte de YouTube connectat a Zernio.
   - BUNDLE_SOCIAL_API_KEY    : Clau d'API de Bundle.social.
   - BUNDLE_TEAM_ID           : ID de l'equip/workspace a Bundle.social (Snapchat).
   - APIFY_TOKEN              : Token d'accés per al morning_scraper.py.
   - INSTAGRAM_COOKIES        : (Opcional) Contingut de cookies.txt per a yt-dlp.

12. REGLES INVARIABLES DEL SISTEMA
-------------------------------------------------------------------------------

1. Retall de Facebook: Mai exportar la versió de Facebook per sobre de 85 segons.
2. Text Shorts: Mai deixar punt final a short_hook ni puntuació òrfena flotant.
3. Color groc: Tota paraula en negreta (**) s'ha de pintar obligatòriament en #e3b100.
4. Traçabilitat: Cap vídeo pot publicar-se sense el seu 'ID: #{tracking_id}' al caption.
5. Sincronització: El 'git push' a GitHub s'ha de completar amb èxit SEMPRE ABANS
   de cridar les APIs de publicació per evitar errors 404 de descàrrega de vídeo.
6. Disclaimer legal: Mantenir invariable DISCLAIMER_TEXT a la darrera línia de cada caption.
